# Admin-Assistant-GTA5RP


Данный проект разработан для администраторов проекта GTA5RP.com.

Он предназначен для помощи хелперам и администраторам в работе с правилами проекта, законодательной базой сервера, а также содержит готовые ответы на частые вопросы и обращения в репорте.

На данный момент проект реализован исключительно для сервера LA PUERTA. В приложении предусмотрена авторизация через Discord. Для получения доступа необходимо обратиться к разработчику; без доступа авторизация будет отклонена, и использование функционала приложения станет невозможным.

О любых багах сообщайте в личные сообщения Discord: gnom4k. Указывайте суть проблемы, шаги для воспроизведения и прикладывайте видеозапись или скриншот.

Предложения по улучшению и добавлению нового функционала также принимаются через Discord: gnom4k.
